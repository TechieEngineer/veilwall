# Changelog

## 1.0.0-beta.1

- Add synthetic IPv4/IPv6 policy evaluation with ordered active and shadow rules.
- Add editable policies, import/export JSON and sample policy.
- Add synthetic traffic samples, SSE streaming, a traffic lab and browser-only evaluator.
- Add local scoped API key issuance, hashed SQLite storage, expiry and revocation.
- Add integration endpoints and automated tests; update CI, release and documentation.
- Native packet enforcement remains disabled; this is not the stable 1.0 release.

## 0.1.0

- Initial Go/React/SQLite foundation, rule transactions, rollback, audit history, CI and Pages demo.
